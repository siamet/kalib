ERROR: "ImportError: DLL load failed while importing QtWidgets"

SOLUTION (Try in order):

1. INSTALL VISUAL C++ REDISTRIBUTABLES (Fixes 90% of cases)
   Download: https://aka.ms/vs/17/release/vc_redist.x64.exe
   Run as Administrator → Restart computer → Try again

2. REINSTALL PYSIDE6 WITH STABLE VERSION
   .venv\Scripts\activate
   uv pip uninstall PySide6
   uv pip install PySide6==6.6.3.1
   python -c "from PySide6.QtWidgets import QApplication; print('OK')"

3. RECREATE THE ENVIRONMENT FROM SCRATCH
   rmdir /s /q .venv
   uv venv --python 3.12
   .venv\Scripts\activate
   uv pip install -r requirements.txt

   If DLL errors persist, try Python 3.11 instead of 3.12:
   uv venv --python 3.11

4. FULL TROUBLESHOOTING GUIDE
   See docs/WINDOWS_SETUP.md for comprehensive solutions
