SOLUTION (Try in order):

1. INSTALL VISUAL C++ REDISTRIBUTABLES (Fixes 90% of cases)

   conda activate kalib
   pip uninstall PySide6 -y

   python -c "from PySide6.QtWidgets import QApplication; print('OK')"

3. USE WINDOWS-OPTIMIZED ENVIRONMENT
   conda deactivate
   conda env remove -n kalib
   conda env create -f environment_windows.yml
   conda activate kalib
